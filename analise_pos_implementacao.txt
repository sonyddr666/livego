3. ⚠️ NOVO BUG: query: Array(1) causa 400 no Ghost Search
================================================================================

EVIDÊNCIA NOS LOGS:

  useLiveAPI.ts:552 [Tool] Function called: ghost_search 
      {model: 'best', query: Array(1), focus: 'web'}  ← ARRAY!
  
  dataFunctions.ts:598 POST http://localhost:3000/api/ghost/search 
      400 (Bad Request)
  dataFunctions.ts:609 [Ghost-Search] HTTP 400 | Time: 0.5s | Body: 277

O QUE ACONTECEU:
  O Gemini mandou a query como um ARRAY em vez de string:
    query: ["notícias nos Estados Unidos"]  ← ERRADO
  em vez de:
    query: "notícias nos Estados Unidos"    ← CORRETO
  
  Isso acontece porque o schema do ghost_search no skillsStore.ts
  define query como "type: 'string'", mas o modelo Gemini 
  ocasionalmente envia como array. É comportamento do modelo, 
  não do nosso código.

  A API do Ghost rejeita o array com 400 Bad Request.

POR QUE ACONTECE:
  Na SEGUNDA busca, o Gemini mandou query como Array(1). Na terceira
  busca (mesma sessão, reconectada), mandou como string "notícias nos
  Estados Unidos" e aí funcionou (HTTP 200, 14.7s).
  
  Parece ser intermitente, dependendo de como o modelo formata os args.

O QUE CORRIGIR (em dataFunctions.ts, função ghostSearch):
  Antes de enviar para a API, normalizar a query:
  
  // No início de ghostSearch():
  if (Array.isArray(args.query)) {
    args.query = args.query.join(' ');
  }

IMPACTO: Médio. Quando acontece, a busca falha com 400. Simples de
  corrigir com 2 linhas.
